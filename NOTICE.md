# Notices

## What this project is

This project is one mod. It contains Lua source, one picture made of text, and
documentation. It changes the position of a light in a display effect.

## What this project does not contain

This project contains no game data. It contains no ROM image, no image file
extracted from a game, no audio, no text, and no character or place name from
any game. It does not read, convert, or distribute any game data.

Do not send game data with this mod. Do not ask the author for game data.

## What you must supply

This mod needs a host engine to run. This project does not include that
engine. Get the engine from its own project. Follow the terms of that project.

The engine needs data that you must produce from software that you own. This
project gives no method to obtain that data. It gives no link to that data.

## Hardware names in the source

The source refers to a USB vendor identifier and a product identifier. It also
refers to byte positions in a device report. These identify hardware. They are
facts about an interface. They are not the property of this project.

## The name GBCFX

`GBCFX` is a module name in the host engine. `GBC FX` is a menu row in that
engine. The mod uses these names because it calls that module. The names come
from the host engine, not from this project.
